# TinyStress-15K reference prompts

The ten WAV files in `prompts/` are reference clips selected from the [TinyStress-15K](https://huggingface.co/datasets/slprl/TinyStress-15K) training split. `prompts.json` maps each synthetic voice to its clip and transcription. TinyStress-15K is licensed under [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/); credit the dataset authors and observe its terms when redistributing or using these audio clips. The test shard is downloaded separately.
